# Changelog — ZohaOnline 2.6.0

- Version: `2.6.0`
- Marker: `ZOHA-EDITORIAL-260`
- Release name: «کارگاه محتوای ضحی»

## رابط کاربری
- طراحی جدید ویترین عمومی جست‌وجومحور با هویت سرمه‌ای/طلایی و RTL.
- طراحی جدید داشبورد فیش‌بردار و ناوبری نقش‌محور.
- بازطراحی فرم ثبت فیش در چهار مرحله با Preview، Draft، Autosave و Submit.
- نمایش خلاصه و کلمات کلیدی قبل از متن اصلی در جزئیات فیش.

## مدل محتوا و نمایه‌سازی
- افزودن «کاربردهای تبلیغی» سلسله‌مراتبی با انتخاب اصلی/تکمیلی.
- افزودن «پیشنهاد شیوه ارائه» به‌صورت اختیاری و قابل جست‌وجو.
- وابستگی «محتوا» به «جنس محتوا».
- جداسازی منبع اصلی از توضیحات منبع.
- موضوعات اختیاری با کلید پردازش و محمول اختیاری.
- مخاطب عمومی/اختصاصی با جنسیت، سن، صنف، کشور و شهر چندانتخابی.
- افزودن فیش‌برداری اختصاصی و پیوست‌های فیش.
- ذخیره و نمایش روز/ماه شمسی مناسبت‌ها.
- عنوان فیش اختیاری؛ متن اصلی لازم و ذخیره منوط به حداقل یک نمایه ساختاریافته.
- اعتبارسنجی کلمات کلیدی نسبت به متن اصلی و جلوگیری از تکرار نمایه‌ها.

## Backend
- Migration `0011_zoha_260_editorial_workflow`.
- API ویرایش گزینه/منبع شخصی و metadata مناسبت.
- جست‌وجوی عمومی با FTS/Trigram و Pagination.
- ذخیره فیش‌های عمومی برای کاربران واردشده و شمارش بازدید عمومی.
- ویرایش کنترل‌شده گزینه‌ها و منابع شخصی از خود فرم فیش.
- حفظ Baselineهای 2.5 شامل Team access، Lifecycle واحد، AI review workflow و Sermon Artifact.

## تکمیل نهایی مبتنی بر اسناد فرانت و اصلاحیه نسخه ۲
- افزودن انتخاب مدیریتی «منتخب صفحه عمومی» و ترتیب نمایش برای فیش‌های عمومی.
- افزودن ردیف موضوعات پرکاربرد، مرور جدیدترین/پربازدیدترین و CTA عضویت در صفحه عمومی.
- افزودن فیلتر برچسب/کلمه کلیدی و Drawer موبایلی فیلترها در جست‌وجوی عمومی.
- افزودن پیام‌های موفقیت/خطا در پوسته عمومی.
- تکمیل فیلتر «فیش‌های من»: وضعیت، جنس محتوا، موضوع، سطح دسترسی و بازه تاریخ.
- افزودن صفحه مدیریت «دسته‌بندی‌های اختصاصی» برای فیش‌بردار.
- تکمیل مخاطب اختصاصی با انتخاب استاندارد و قابل افزودن/ویرایش برای صنف، کشور و شهر.
- نمایش متمایز گزینه اصلی در کاربرد تبلیغی و پیشنهاد شیوه ارائه.
- اصلاح داده نمایشی تا فیش‌های منتشرشده واقعاً در ویترین عمومی دیده شوند.
- تکمیل کارت‌های داشبورد فیش‌بردار با وضعیت «تأییدشده‌ها» مطابق سند تحویل فرانت.
- افزودن دسترسی مستقیم «تماس با ما» در هدر عمومی مطابق مرجع صفحه عمومی.
