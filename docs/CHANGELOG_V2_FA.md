# تغییرات نسخه ۲ حرفه‌ای

- بازطراحی کامل ظاهر، سایدبار، نوار بالا، ورود، ثبت‌نام و صفحات مدیریتی
- افزودن Bootstrap RTL، Font Awesome، Animate.css، Vazirmatn، Chart.js، Select2 و Quill
- جایگزینی ادبیات «تحقیق» با «فیش» در رابط اصلی
- افزودن مدل منبع ساختاریافته
- افزودن تحلیل مستقل برای هر موضوع
- افزودن گزینه‌های شخصی و فرایند تأیید مدیر
- افزودن تشخیص مشابهت و جلوگیری از داده تکراری
- افزودن ادغام امن گزینه‌ها با حفظ ارتباط داده‌های قدیمی
- افزودن فرم چندبخشی، ذخیره پیش‌نویس و هشدار تغییر ذخیره‌نشده
- افزودن مخاطب ترکیبی و چندگانه
- بازطراحی جست‌وجو با شرط‌های نامحدود متن و نمایه
- افزودن داشبورد و گزارش‌های آماری متنوع
- حفظ گردش ارزیابی، نسخه‌بندی، اعلان و نقش‌ها
