# تغییرات نسخه پنجم

نسخه پنجم بازطراحی صفحه عمومی، مقاوم‌سازی رابط موبایل و اصلاح مسیرهای ایجاد داده را یکپارچه می‌کند. پنجره‌ها پیش از نمایش به بدنه سند منتقل می‌شوند، ترتیب لایه‌ها صریح است و backdrop یتیم پاک می‌شود. جداول در صفحه باریک اسکرول کنترل‌شده دارند و متن سلول‌ها و دکمه‌ها شکسته می‌شود. کارت‌های آماری به شبکه دو یا یک‌ستونه تبدیل می‌شوند.

صفحه نخست شامل جست‌وجوی سراسری، سه درگاه محتوایی و پنل مزیت‌هاست. واژگان «ریز جنس محتوا» و «ریز موضوع» حفظ شده‌اند. مطابق اصلاحیه پنجم، اطلاعات جغرافیایی مخاطب شامل کشور، شهر و اقلیم حذف و در مهاجرت داده پاک‌سازی شده است.
